
# Airport-Luggage-Handling-API


Assignment:
-----------
The functionalities to demonstrate:
– Successful login by any one of the staff members
– Invalid login by a staff member
– Adding a new flight by the administrator
– Retrieving a flight’s details using the unique flight ID by a staff member
– Viewing all passengers of a flight using the unique flight ID by a staff member
– Adding a new passenger by the administrator
– Viewing all the passengers by the administrator
– Removing a passenger using either ticket number or passenger ID by the administrator
– Retrieving a passenger information using the ticket number by a staff member
– Adding a bag for a passenger by a staff member
– Retrieving a bag using its unique ID by a staff member
– Removing a bag using its unique ID by a staff member
– Changing the location/status of a bag using its unique ID by a staff member
– Changing the status of a passenger using the ticket number by a staff member
– Viewing the gate information using the gate number
– Viewing all the bags at a gate using the gate number or flight ID by a ground staff member
